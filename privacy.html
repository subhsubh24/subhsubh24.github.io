Privacy Policy

Last updated October 31, 2026

"Home Assistant" here is a private home-automation app used by one person, Subhodip Mukherjee, with his own Google account. It has no other users.

What it accesses

  • Gmail (read-only): to read the owner's own receipts, reservations, travel and delivery emails. It cannot send, delete or change email.
  • Google Nest (Smart Device Management): to read and set the owner's own thermostat.

How the data is used

Only to run the owner's own apartment automations. The data stays on the owner's own computer and in his own private database. It is never sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
